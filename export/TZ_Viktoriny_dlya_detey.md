# Техническое задание
## Мобильная игра «Викторины для детей»

Версия документа: 1.0 · Дата: 24.09.2026
Интерактивный прототип: `Викторины для детей.dc.html`, он служит визуальным эталоном. Иконки лежат в папке `icons/`.

---

## 1. Общие сведения

| Параметр | Значение |
|---|---|
| Название | Викторины для детей |
| Жанр | Обучающая казуальная игра-викторина |
| Платформы | iOS 15+, Android 8.0+ (API 26+) |
| Ориентация | Только портретная |
| Аудитория | Дети 5–12 лет, родители |
| Язык | Русский (архитектура с учётом будущей локализации) |
| Монетизация | Реклама (3 места), внутриигровые покупки |
| Сервер | **Отсутствует.** Приложение работает полностью офлайн |

### 1.1. Цель
Ребёнок в игровой форме отвечает на вопросы по разным темам. Его удерживают прогресс по карте уровней, награды, серии дней и достижения.

### 1.2. Рекомендуемый стек
- Flutter или React Native, чтобы вести одну кодовую базу на iOS и Android.
- Локальное хранилище: SQLite (sqflite / expo-sqlite) или Hive / MMKV.
- Контент (вопросы) лежит в JSON-файлах внутри сборки приложения.

## 2. Архитектура без сервера

### 2.1. Хранение данных
Все данные пользователя хранятся локально на устройстве:

| Сущность | Поля |
|---|---|
| `profile` | name, avatarId, ageGroup (0/1/2), createdAt |
| `wallet` | coins, gems |
| `inventory` | fifty, freeze, life, skip, streakFreeze, ownedAvatars[] |
| `progress` | по каждой паре (topicId, difficulty): список пройденных уровней, звёзды, открытые сундуки |
| `stats` | gamesPlayed, answersTotal, answersCorrect, bestStreak, starsTotal, по дням: questionsAnswered |
| `streak` | current, best, lastPlayedDate, freezeUsedDates[] |
| `achievements` | id, unlockedAt, progress |
| `daily` | questId, date, progress, claimed |
| `settings` | sound, music, vibro, voice, notifications, parentControl, dailyLimitMin, difficultyDefault, language |
| `purchases` | noAds (bool) |
| `ads` | rewardedCoinsToday, date |

### 2.2. Облачная копия прогресса (без своего сервера)
- **Android:** Google Play Games Services → Saved Games.
- **iOS:** iCloud (NSUbiquitousKeyValueStore или CloudKit private database) либо Game Center Saved Games.
- Синхронизация: при запуске, после каждого уровня и при сворачивании приложения. Конфликты разрешаются по правилу «побеждает запись с бо́льшим суммарным XP».
- Если облако недоступно, игра работает полностью локально.

### 2.3. Контент
- Вопросы поставляются внутри приложения: `assets/questions/{topicId}_{difficulty}.json`.
- Новые вопросы приходят с обновлением приложения в сторе.
- Опционально, без собственного сервера: JSON на статическом хостинге (GitHub Pages / Firebase Hosting / S3), который приложение скачивает и кеширует. Не входит в MVP.

Формат вопроса:
```json
{
  "id": "animals_e_001",
  "topic": "animals",
  "difficulty": 0,
  "level": 1,
  "text": "Какое животное самое большое на Земле?",
  "image": "q/animals_001.png",
  "options": ["Слон", "Синий кит", "Жираф", "Бегемот"],
  "answer": 1,
  "explanation": "Синий кит вырастает до 30 метров."
}
```
Порядок вариантов ответа перемешивается при каждом показе.

### 2.4. Покупки
- Google Play Billing (Android), StoreKit 2 (iOS). Проверка покупок выполняется на устройстве средствами платформы.
- **Кнопку «Восстановить покупки» не делаем.** Покупка «Отключить рекламу» (non-consumable) восстанавливается автоматически при каждом запуске: `Transaction.currentEntitlements` в StoreKit 2 и `queryPurchasesAsync` в Play Billing. Такой автоматической проверки достаточно для требования Apple о восстановлении покупок.

## 5. Описание экранов

### 5.1. Приветствие
Показывается при первом запуске, если профиля нет.
- Маскот (лиса) в круге, декоративные «❓» и «⭐».
- Заголовок «Викторины для детей», подзаголовок.
- Кнопка **«Начать играть»** ведёт к созданию профиля.
- Кнопка **«Восстановить прогресс»** запрашивает сохранение из Google Play Игр / Game Center / iCloud. Если сохранение найдено, игра загружает его и открывает главную. Если нет, показывается сообщение «Сохранений не найдено» и предложение создать героя.
- Подпись: регистрация и пароли не нужны.

### 5.2. Создание профиля («Создай героя»)
- Превью аватара и имени обновляются в реальном времени.
- Поле **«Как тебя зовут?»**: 1–14 символов, пробелы по краям обрезаются, стоп-слова фильтруются локальным списком.
- **Персонаж**: 6 вариантов. Выбранный при регистрации персонаж выдаётся бесплатно.
- **Возраст**: 5–7 / 8–10 / 11+. От него зависит сложность по умолчанию: Легко / Средне / Сложно.
- Кнопка **«Поехали!»** неактивна (прозрачность 45 %), пока имя пустое.
- Подпись о том, что почту и телефон мы не собираем.
- После нажатия профиль сохраняется, игрок получает стартовый набор (п. 7.6) и попадает на главную.

### 5.3. Главная (карта уровней)
1. **Шапка**: аватар, «Привет, {имя}!», «Уровень N · XP/нужно». Справа плашки серии «🔥 N» (ведёт на экран серии) и монет.
2. **Карточка серии**: градиент, «N дней подряд!», 7 кружков Пн–Вс: пройдено ✓, сегодня 🔥 с пунктирной рамкой, будущие дни пустые.
3. **Задание дня**: название, прогресс-бар, награда.
4. **Текущая тема**: цветная плашка «Тема · Сложность / Название» и кнопка «Сменить», которая открывает экран тем.
5. **Карта уровней**: вертикальная змейка из круглых узлов со смещением по X (0, 55, 85, 55, 0, −55, −85, −55…).
   - Пройденный уровень: цвет темы, номер, под узлом 1–3 звезды.
   - Текущий уровень: фиолетовый, крупнее (78 px), кольцо-подсветка, над ним подсказка «НАЧАТЬ!», пульсирующая анимация.
   - Закрытый уровень: серый, 🔒.
   - Сундук 🎁 открывается после прохождения предыдущего уровня и даёт случайную награду.
   - Босс 👑: последний узел секции, 84 px.
   - Нажатие на текущий или пройденный уровень запускает викторину. Нажатие на закрытый показывает тост «Сначала пройди предыдущие уровни».
   - При открытии экрана карта автоматически прокручивается к текущему уровню.
6. **Рекламный баннер** 320×50 над нижним меню (п. 8).

### 5.4. Темы
- Заголовок «Темы».
- **Переключатель сложности** из 3 сегментов, под ним подсказка:
  - Легко: 20 с на вопрос, 3 жизни, для 5–7 лет.
  - Средне: 15 с, 3 жизни, для 8–10 лет.
  - Сложно: 10 с, 2 жизни, для 11+ лет.
- **Сетка тем** в 2 колонки: эмодзи, название, «пройдено/всего», прогресс-бар цвета темы. У выбранной темы рамка цвета темы.
- Нажатие на тему делает её текущей и открывает главную.
- Прогресс хранится отдельно для каждой сложности.

### 5.5. Уровень викторины
- **Верхняя панель**: крестик выхода (с подтверждением «Выйти? Прогресс уровня не сохранится»), прогресс-бар уровня, жизни ❤️ (потерянные полупрозрачные).
- **Строка**: «Вопрос N из M · Тема» и таймер. Таймер фиолетовый, при ≤5 с становится красным и пульсирует, при заморозке голубой «❄».
- **Карточка вопроса**: иллюстрация (фон цвета темы, 130 px), текст вопроса.
- **4 варианта ответа** с буквами А/Б/В/Г.
  - После выбора верный ответ подсвечивается зелёным. Ошибочный выбор подсвечивается красным, остальные варианты тускнеют до 60 %.
  - Повторный выбор невозможен.
- **Подсказки** (3 кнопки со счётчиком):
  - ✂️ 50/50 убирает 2 неверных ответа (они становятся полупрозрачными и не нажимаются). Один раз за вопрос.
  - ⏸️ Стоп останавливает таймер до конца вопроса.
  - ⏭️ Пропуск переходит к следующему вопросу без потери жизни и без награды.
  - Если подсказок 0 или ответ уже дан, кнопка неактивна (45 %). Нажатие с нулевым счётчиком открывает мини-окно «Купить за 🪙».
- **Нижняя панель ответа** выезжает снизу:
  - Верно: зелёная, «Верно!» / «Молодец!» / «Супер!», «+10 монет и +8 XP».
  - Неверно: красная, «Ой, не то!» и «Правильный ответ: …». Если есть explanation, показывается одна строка пояснения.
  - Время вышло: «Время вышло!».
  - Кнопка «Продолжить».
- Если закончились жизни, открывается окно «Жизни закончились»: «Продолжить за ❤️ Доп. жизнь» (если есть в инвентаре) или «Завершить». Уровень засчитывается по фактическим ответам.
- Во время викторины реклама **не показывается**.
- Звуки: верно, неверно, тик последних 5 секунд. Вибрация при ошибке (если включена).

### 5.6. Результат
- Аватар 130 px, звёзды (центральная крупнее, незаработанные серые), заголовок по количеству звёзд:
  0 «Попробуй ещё!», 1 «Неплохо!», 2 «Отлично!», 3 «Потрясающе!».
- Подпись «{Тема} · уровень N пройден».
- 3 плашки: Верно X/M, Монеты +N, Опыт +N.
- **Блок rewarded-рекламы «Удвоить награду ×2»** (п. 8). После просмотра на его месте плашка «Награда удвоена! 🎉».
- Кнопки: «Следующий уровень» (основная), «Ещё раз», «На карту».
- Анимации: звёзды появляются по очереди, счётчики монет и XP «набегают», при 3 звёздах конфетти.

### 5.7. Магазин
- Заголовок и балансы 🪙 и 💎.
- **«Бесплатные монеты»**: rewarded-реклама, +100 🪙, до 5 раз в день, счётчик «осталось N из 5».
- **Подсказки** (сетка 2×2): иконка, название, описание, «есть: N», кнопка цены. Если монет не хватает, кнопка полупрозрачная, а по нажатию появляется тост «Не хватает монет».

| Товар | Цена |
|---|---|
| ✂️ 50 на 50 | 150 🪙 |
| ⏸️ Стоп-время | 120 🪙 |
| ❤️ Доп. жизнь | 200 🪙 |
| ⏭️ Пропуск | 100 🪙 |
| 🧊 Заморозка серии | 50 💎 |

- **Персонажи** (сетка 3×2): 🦊, 🐼 бесплатно; 🐸 300, 🐯 400, 🦄 500, 🐙 800 🪙. Состояния: «Выбран» (фиолетовая рамка), «Выбрать», цена (обесцвеченный). Покупка сразу выбирает персонажа.
- **Кристаллы** (реальные деньги): 50 💎 за 149 ₽; 180 💎 за 399 ₽ (метка «ВЫГОДНО»); 500 💎 за 899 ₽.

- **Все покупки за реальные деньги проходят через родительский барьер (п. 9.1).**

### 5.8. Профиль и статистика
- Кнопка ⚙️ ведёт в настройки.
- Фиолетовая карточка: аватар, имя, «Уровень N · звание», XP-бар, «X / Y XP до уровня N+1».
- Звания: 1–2 Новичок, 3–5 Ученик, 6–9 Знаток, 10–14 Мудрец, 15+ Профессор.
- Статистика 2×2: игр сыграно, % верных ответов, лучшая серия, звёзд собрано.
- «Активность за неделю»: столбчатая диаграмма Пн–Вс (число вопросов), сегодняшний день выделен цветом, справа сумма за неделю.
- «Точность по темам»: до 5 тем с наибольшей точностью, полоса цвета темы и %.
- «Достижения»: 4 последних открытых значка и ссылка «Все X/Y».

### 5.10. Серия (стрик)
- Кнопка «Назад» (`<`) ведёт на главную. Фон с тёплым градиентом.
- Крупно 🔥, число дней, «дней подряд», подпись «Лучшая серия — N дней. Ещё K дня до …».
- Календарь недели Пн–Вс.
- «Награды за серию»:

| Дней | Награда |
|---|---|
| 3 | 100 🪙 |
| 7 | Сундук с подсказками (2× 50/50, 1× Стоп, 1× Пропуск) |
| 14 | Персонаж 🦄 Единорог |
| 30 | Золотая рамка профиля + 20 💎 |

- Статусы наград: «Получено», «через N дней», у недоступных прозрачность 55 %.
- Блок «Заморозка серии» с количеством в инвентаре.

### 5.11. Настройки
Кнопка «Назад» (`<`) ведёт в профиль. Настройки разбиты на группы-карточки, в каждой строке иконка в цветном квадрате 36×36.

**Звук**: Звуки (вкл/выкл), Музыка (вкл/выкл), Вибрация (вкл/выкл), Озвучка вопросов (вкл/выкл; системный TTS, для детей, которые плохо читают).
**Игра**: Язык (Русский), Сложность по умолчанию (Легко/Средне/Сложно), Напоминания (вкл/выкл, локальные уведомления).
**Для родителей**: Родительский контроль (вкл/выкл), Лимит в день (Без лимита / 15 / 30 / 60 мин).

Изменения в разделе «Для родителей» доступны только после родительского барьера.
Переключатель: 52×30, включён зелёный `#2DC78A`, выключен `#DDD6E6`, анимация 0,2 с.
Внизу подпись «Версия X.Y.Z».

## 6. Игровая механика

### 6.1. Структура контента
- 10 тем × 3 сложности.
- В каждой паре «тема + сложность» 30 уровней, разбитых на 3 секции по 10 уровней.
- Секция на карте состоит из 12 узлов: уровни 1–4, 🎁, уровни 5–8, 🎁, уровень 9, 👑 босс (уровень 10).
- Обычный уровень: 5 вопросов. Босс: 10 вопросов, подсказки 50/50 недоступны.
- Следующий уровень открывается после прохождения текущего, минимум на 1 звезду.
- Итого контента: 10 × 3 × 30 × 5 ≈ 4500 вопросов. **Для MVP** достаточно 4 тем × 3 сложности × 10 уровней ≈ 600 вопросов.

### 6.2. Параметры сложности
| | Легко | Средне | Сложно |
|---|---|---|---|
| Время на вопрос | 20 с | 15 с | 10 с |
| Жизни | 3 | 3 | 2 |
| Множитель монет | ×1 | ×1,5 | ×2 |

### 6.3. Звёзды (обычный уровень, 5 вопросов)
5 верных — 3 ⭐; 3–4 — 2 ⭐; 1–2 — 1 ⭐; 0 — уровень не пройден.
Босс (10 вопросов): 9–10 — 3 ⭐; 6–8 — 2 ⭐; 4–5 — 1 ⭐.
При повторном прохождении засчитывается лучший результат. Монеты за повтор начисляются в размере 50 %.

### 6.4. Награды
- Верный ответ: 10 🪙 × множитель сложности, 8 XP.
- Бонус за 3 звезды: +20 🪙.
- Сундук: случайно одно из трёх: 50–150 🪙 / 1 подсказка / 3–5 💎.
- Босс: 100 🪙 + 5 💎.

### 6.5. Уровень игрока
XP для перехода на следующий уровень: `100 + 50 × (N − 1)`. Ур.1→2: 100 XP, ур.7→8: 400 XP.
При повышении уровня открывается окно «Новый уровень!» с наградой 50 🪙 × N.

### 6.6. Серия дней
- День засчитывается, если за календарный день (по локальному времени устройства) пройден хотя бы 1 уровень.
- Если день пропущен и есть 🧊 заморозка, она расходуется автоматически и серия сохраняется. Если заморозки нет, серия сбрасывается до 0.
- Защита от перевода часов назад: если дата меньше lastPlayedDate, серия не начисляется.

### 6.7. Задание дня
Одно задание в день, выбирается детерминированно из пула по дате. Примеры:
- Ответь правильно на 10 вопросов (+50 🪙).
- Пройди 2 уровня на 3 звезды (+60 🪙).
- Сыграй в новой теме (+40 🪙).
- Пройди уровень без подсказок (+50 🪙).
Награда забирается нажатием на выполненную карточку.

### 6.8. Стартовый набор
300 🪙, 5 💎, 2× 50/50, 1× Стоп, 1× Пропуск, 1× 🧊, персонажи 🦊 и 🐼.

## 8. Реклама

Реклама показывается **только в 3 местах**. Межстраничной рекламы (interstitial) нет.

| № | Место | Формат | Правила |
|---|---|---|---|
| 1 | Главная, над нижним меню | Баннер 320×50 | Только на главной. Не перекрывает контент. Подпись «Реклама». Скрывается после покупки «Отключить рекламу» |
| 2 | Результат уровня | Rewarded video «Удвоить награду ×2» | Только по нажатию. Один раз на уровень. Если за уровень заработано 0 монет, не показывается |
| 3 | Магазин | Rewarded video «Бесплатные монеты +100» | Только по нажатию, до 5 раз в сутки |

- Награда начисляется только по колбэку `onUserEarnedReward`. Если видео не загружено, кнопка неактивна с подписью «Видео пока нет».
- После покупки «Отключить рекламу» баннер скрывается. Rewarded-видео остаются, потому что пользователь запускает их сам.
- Во время викторины реклама не показывается никогда.
- Рекламные сети: Yandex Mobile Ads и/или Google AdMob. Обязательные условия:
  - включён режим детского контента: `tagForChildDirectedTreatment = true`, `maxAdContentRating = G`, для Yandex — настройка детской аудитории;
  - без персонализации;
  - на Google Play — только SDK из программы Families Self-Certified Ads SDK.
- **iOS:** в категории Kids App Store сторонняя реклама сильно ограничена. Нужно либо не публиковать игру в категории Kids, либо заранее согласовать рекламную сеть с требованиями Apple (п. 1.3 и 5.1.4 App Review Guidelines).

## 9. Безопасность детей и законодательство

### 9.1. Родительский барьер
Показывается перед:
- покупкой за реальные деньги;
- переходом по внешним ссылкам (политика, оценка приложения);
- изменением раздела «Для родителей».

Реализация: окно «Попроси взрослого» с заданием вроде «Сколько будет 7 × 8?» и вводом числа. Задания генерируются случайно, после 3 ошибок барьер блокируется на 1 минуту.

### 9.2. Лимит времени
Если задан дневной лимит, по его истечении показывается экран «На сегодня всё! Возвращайся завтра». Продлить время можно только через родительский барьер. Во время уровня лимит не прерывает игру, а срабатывает после его окончания.

### 9.3. Данные
- Персональные данные не собираются и не передаются, имя хранится только на устройстве.
- Без аналитики с идентификаторами. Если аналитика нужна, использовать только Firebase Analytics с отключённым Ad ID или локальные счётчики.
- Нужны политика конфиденциальности (ссылка в сторе и в приложении через родительский барьер) и заполненный Data Safety / Privacy Nutrition Label.
- Требования, которые нужно соблюсти: 152-ФЗ (РФ), COPPA, Google Play Families Policy, Apple Kids Category.

## 10. Звук, анимации, отклик

**Звуки:** нажатие кнопки, верный ответ, неверный ответ, тик таймера (последние 5 с), получение монет, открытие сундука, звёзды на экране результата, повышение уровня, достижение. Фоновая музыка: спокойный зацикленный трек 60–90 с.
Музыка приглушается при воспроизведении озвучки и видеорекламы.

**Анимации (длительность 150–400 мс, easing ease-out, «пружина» для наград):**
- нажатие объёмных кнопок: сдвиг вниз на 4 px;
- пульсация текущего узла карты и подсказки «НАЧАТЬ!»;
- выезд нижней панели ответа снизу;
- покачивание неверно выбранного варианта (shake 300 мс);
- последовательное появление звёзд и конфетти на результате;
- «полёт» монет к счётчику в шапке;
- плавное заполнение прогресс-баров.

**Вибрация:** лёгкая при нажатии, средняя при ошибке, «успех» при 3 звёздах.

## 13. Критерии приёмки MVP
1. Приложение запускается и работает без интернета (кроме рекламы и облачной синхронизации).
2. Можно пройти путь «Приветствие → Создание профиля → Главная → Уровень → Результат» без ошибок.
3. Прогресс, монеты, инвентарь, серия и настройки сохраняются после перезапуска и переустановки (при включённом облаке).
4. Таймер, жизни, подсказки и начисление наград работают по разделу 6.
5. Реклама показывается только в 3 местах из раздела 8. Во время викторины реклама не появляется.
6. Покупки за реальные деньги проходят через родительский барьер. «Отключить рекламу» восстанавливается автоматически.
7. Интерфейс соответствует прототипу: цвета, шрифты, отступы (допуск ±2 px).
8. Работает на экранах от 360×640 до планшетов; на планшете контент центрируется, ширина до 600 pt.
9. Время холодного старта не больше 2 с, анимации 60 fps на устройствах среднего уровня.
